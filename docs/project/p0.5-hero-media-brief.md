# P0.5 JuanProperty Hero Media Brief

## Visual direction

Use Casa Aurelia only as a mood reference: full-bleed architectural photography,
warm editorial restraint, generous negative space, and almost imperceptible
camera movement. Reinterpret that mood for JuanProperty with deep forest and
emerald shadows, warm ivory architecture, restrained golden-hour light, and a
credible Philippine property setting rather than a luxury-listing advertisement.
Keep the left half dark, calm, and low-detail for the existing headline and
calls to action; place the architectural focal point between 65% and 85% of the
frame so it survives the hero's right-biased mobile crop.

## Generate it

1. Go to [MuAPI](https://muapi.ai/) to create or sign in to an account and obtain access to the selected generation model.
2. Open [Open Generative AI](https://github.com/anil-matcha/open-generative-ai) and use its hosted studio, desktop app, or self-hosted workflow to generate the media.
3. Enter the MuAPI key only in Open Generative AI's documented credential flow. Never paste it into this project's source code, `.env` files, screenshots, or Git history.
4. Generate Image A first. Generate Image B second, using Image A as a visual reference.
5. Upload both images to Kling when its selected workflow accepts additional references. Set Image A as both the Start Frame and End Frame; Image B is the secondary cinematic reference. Generate one 8-second video.
6. If that Kling workflow accepts only Start Frame and End Frame, use Image A for both and retain the video prompt's requested middle-of-video movement. Do not create a second clip.
7. Convert Image A to AVIF with [avify.dev](https://avify.dev/). Convert the generated MP4 to WebM with [FreeConvert's MP4-to-WebM converter](https://www.freeconvert.com/mp4-to-webm), while keeping the original MP4 as the Safari fallback.
8. Put the three final files in `public/`, run the app, and review the hero on desktop and mobile. Confirm the headline remains readable, the subject survives the crop, the video loop join is unobtrusive, reduced-motion shows the poster, and both the WebM and MP4 paths play correctly.

## 1. Image prompt A — Nano Banana

Create a cinematic, professional, ad-quality 16:9 hero photograph for JuanProperty, a Philippine real estate and land management platform used by property managers, developers, brokers, and landlords. Show a refined contemporary Philippine residential development at blue hour: warm ivory limestone and timber architecture, deep emerald tropical landscaping, a subtle surveyed land edge or discreet boundary markers, humid atmospheric depth, and a restrained warm glow from interior practical lights. Compose the principal building and recognizable property details between 65% and 85% of the frame, with the strongest focal point near the right third so it remains visible in a narrow mobile crop centered far right. Reserve the entire left 50% as clean, dark, low-detail negative space in deep forest-obsidian tones for a large headline, supporting copy, and two calls to action; avoid bright windows, strong edges, faces, or visual clutter in that region. Use an elevated editorial-real-estate sensibility inspired by warm architectural magazines: natural materials, precise geometry, credible Philippine tropical context, subtle gold warmth, rich but restrained contrast, and premium realism without looking like a generic resort advertisement. No readable text, signs, logos, watermarks, interface elements, screens, maps, fake documents, fake code, or product screenshots. Nano Banana settings: 16:9

## 2. Image prompt B — Nano Banana

## 3. Video prompt — Kling 3 Standard Image-to-Video

Create one continuous premium eight-second cinematic real-estate film for JuanProperty. Upload Image A and Image B as available references, using Image A as both the Start Frame and End Frame wherever the interface allows and Image B only as the secondary reference for the middle movement. Begin settled in Image A's exact master composition, then introduce a slow, restrained lateral camera drift and shallow architectural parallax inspired by Image B; allow only subtle tropical leaf movement, a soft sweep of warm practical light across limestone and glass, minute reflection changes, and gentle humid atmosphere. Through the final third, calmly reverse and settle back into Image A's opening camera position, lighting, reflections, and framing. Keep the full left 50% dark, calm, low-detail, and nearly motionless throughout so the existing headline and calls to action remain readable; keep the main building focal point in the right-side mobile-safe region. Produce a polished architectural advertisement with continuous natural motion and stable geometry. No cuts, whip pans, fast motion, random zooms, circular camera movement, sudden transformations, new objects, people entering or leaving, warped architecture, flicker, readable text, logos, watermarks, fake UI, or major composition changes. Make the final frame match Image A as closely as possible so the single video can loop smoothly in the browser. Kling settings: Image-to-Video, 16:9, 8 seconds, use Image A as the Start Frame and End Frame; use Image B as an additional reference when supported.

## Asset delivery plan

- **Poster:** Convert Image A only to AVIF. Use [avify.dev](https://avify.dev/) if a local encoder is unavailable.
- **Video:** Encode the single generated eight-second video as WebM for primary delivery and MP4 for Safari fallback. Use [FreeConvert's MP4-to-WebM converter](https://www.freeconvert.com/mp4-to-webm) if needed.
- **Targets:** Deliver 1280×720, muted, 24 fps. Keep `hero-poster.avif` at or below 250 KB and each video file at or below 4 MB.
- **Desktop/mobile treatment:** Retain the existing `object-[85%_center] sm:object-[62%_center]` crop and semantic overlays. Do not create a separate mobile asset.
- **Accessibility:** Keep the image decorative in the implemented hero (`alt=""` and `aria-hidden`). Suggested descriptive handoff text for records: “Contemporary Philippine residential development framed by tropical landscaping at blue hour.” Retain the poster for reduced-motion, save-data, unsupported-video, and failed-playback cases.
- **Loop review:** AI generation cannot guarantee a mathematically perfect seamless loop. Inspect the final-to-first-frame join and the stability of the text-safe area before shipping.
- **Usage rights:** Casa Aurelia is a composition and mood reference only; none of its code or media is shipped. Record the image/video provider, generation date, account owner, and the provider terms that permit commercial use before P0.5 is closed.
