## Supabase Dashboard Configuration

Target project: `JuanProperty` (`bnhylarpwbdwdrpctibn`).

1. In **Authentication > URL Configuration**, set **Site URL** to
   `http://localhost:3000`.
2. Add `http://localhost:3000/auth/callback` and
   `http://localhost:3000/reset-password` to **Redirect URLs**.
3. In **Authentication > Providers > Email**, keep email/password enabled and
   require email confirmation before sign-in.
4. In **Authentication > Emails > SMTP Settings**, enable Custom SMTP and use
   `smtp.gmail.com`, port `465`, the Gmail sender address for both sender and
   username, sender name `JuanProperty`, and a Google App Password.
5. Install the repository's Confirm sign up and Reset password templates with
   subjects `Confirm your JuanProperty email` and
   `Reset your JuanProperty password`.

Never paste the Gmail App Password into chat, `.env.local`, or a tracked file.
